# FileExchanger

Spring Boot-сервис для обмена файлами с использованием MinIO (S3-совместимое хранилище).  
Проект демонстрирует навыки работы с REST API, загрузкой и скачиванием файлов, хранением метаданных и модульным тестированием с использованием Testcontainers и Mockito.

## Стек технологий

- Java 17
- Spring Boot
- MinIO 
- Maven
- Docker
- Testcontainers
- JUnit 5 + Mockito

##  Основной функционал

- REST API для загрузки и скачивания файлов
- Интеграция с MinIO для хранения файлов
- Тестирование с использованием Testcontainers 
- Подключён базовый CI
